# YouTube Clone

A simple YouTube homepage clone built with HTML and CSS as part of my practice with frontend development.

## Features

* Responsive video grid
* Fixed header and sidebar
* Video thumbnails and timestamps
* Channel profile pictures
* Hover tooltips
* Responsive design with media queries
* CSS Grid and Flexbox layouts

## Technologies

* HTML
* CSS

## What I Practiced

This project helped me practice:

* Flexbox
* CSS Grid
* Positioning
* Responsive design
* Media queries
* Hover effects and transitions
* Tooltips
* Organizing CSS into multiple files

## Running the Project

Open `index.html` in your browser or use a local development server such as Live Server.
